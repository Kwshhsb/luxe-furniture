# 🛋️ Luxe Furniture Rental Platform

A full-stack rental marketplace web application that allows users to rent furniture and appliances on a monthly basis instead of purchasing them.

---

## 📌 Project Overview

This platform is designed for students and working professionals who frequently relocate and prefer renting essential furniture and appliances.

Users can:

* Browse products
* Rent items on a monthly basis
* Manage their rentals
* View orders and payments

---

## 🚀 Tech Stack

### Frontend:

* React.js (Vite)
* Tailwind CSS
* Redux Toolkit
* Axios

### Backend:

* Node.js
* Express.js
* MongoDB (Mongoose)

### Other Tools:

* JWT Authentication
* Razorpay (Payment Integration)
* Git & GitHub

---

## ✨ Features

### 👤 User Features:

* User Authentication (Login/Register)
* Browse products by category
* View product details
* Add to cart
* Rent products
* User dashboard

### 🛒 Rental Features:

* Monthly rental system
* Flexible duration (3/6/12 months)
* Rental tracking

### 🔐 Admin Features:

* Add/Edit/Delete products
* Manage users
* Manage orders

## ⚙️ Installation & Setup

### 1️⃣ Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/luxe-furniture.git
cd luxe-furniture
```

---

### 2️⃣ Backend Setup

```bash
cd backend
npm install
npm run dev
```

---

### 3️⃣ Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

---

## 🌐 Environment Variables

Create a `.env` file in backend:

```
MONGO_URI=your_mongodb_connection
JWT_SECRET=your_secret_key
RAZORPAY_KEY=your_key
RAZORPAY_SECRET=your_secret
```
